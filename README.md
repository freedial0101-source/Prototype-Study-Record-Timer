# 学習時間を記録するためのタイマー
自分で使う用にgeminiにプロンプトを出して作成。スマホ用。
<br>手首が痛く作業するのが厳しいので、最低限の機能のみの簡易版です。

## 🚀 公開URL
(https://freedial0101-source.github.io/Prototype-Study-Record-Timer/)

## 📌 現在の状況
以下の機能があります。
<br>・開始時間と終了時間、何をやっていたかの記録
<br>・指定した日の記録の表示
<br>・記録した日ごとの勉強時間の一覧の表示
※　バッテリーの消耗を考慮し、タイマーの表示機能は最低限にとどめました。



## ⏳ 今後の発展について
最終的には、スマホ専用のアプリとして作りたいと考えています。
加えたい機能としては、
<br>・学習時間のグラフ表示
<br>・タグの付与、検索
等があります。

## 📂 リポジトリの構成
* **index.html**：メインプログラム
* **style.css**：css用ファイル
* **script.js**：javascript用ファイル
* **プロンプト.txt**：geminiに出したプロンプト

## 💻 使用技術
* HTML5
* CSS3
* JavaScript (ES6)
